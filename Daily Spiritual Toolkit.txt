1. Version‑wise features (Pro vs Non‑Pro)
	“Naam Jap ToolKit: Daily Spiritual Toolkit”
	Tagline: “Count your naam‑jap, follow the right panchang, and face the right direction—no ads, no tracking.”

MVP (v1 – offline‑first, local‑only)
Goal:
A usable, delightfully simple app for name‑jap + basic panchang + basic compass.

Core user flow:
	Open app → choose a mantra (e.g., “Radha”, “Ram”, “Krishna”) → tap to count (108‑style).
	See “Panchang” screen (read‑only, Refer: https://github.com/bidyashish/panchang).
	See “Compass” screen (simple direction).

Non‑Pro (Free) – v1
	Name‑jap counter (basic)
		Support 1–3 User specified mantras (e.g., “Radha”, “Ram”, “Radhe Krishna”).
		Tap interface:
			Circular / linear counter; reset at 108.
			Basic stats: today’s count, total count, last session.
			No export, no history graphs.
		Anti‑spam / auto‑tap protection
			Minimum time between taps: 0.3 seconds.
			Per‑session reasonable cap (e.g., max 10–20 taps per second; ignore excess).
		Panchang (view‑only, read‑only text)
			Show today’s:
				Tithi, nakshatra, vaar, yoga, karana.
				Sunrise, sunset.
				Simple static “auspicious / inauspicious” note (no maps, no complex logic).
			Data stored locally (JSON or SQLite pre‑computed for 6 months).
		Compass (simple UI)
			Basic compass using device sensor (Android + iOS) and also do a calibration.
			Always show “East”; small label: “Face East for Sun / general puja”.
		Settings (minimal)
			Language: All language support and by default is system language.
			Default mantra selection.
			No ads, no cloud, no user accounts
			All data stored locally (no backend, no analytics by default).

		Dark mode / themes (Pro‑only)
			Light / dark mode.
			One “spiritual‑themed” UI variant (softer colors, subtle backgrounds).
		No ads, no trackers (Pro philosophy)
			As part of Pro unlock: “You’re paying; no ads, no banners, no third‑party tracking.”
		The "Volume Button" Tap (V1.5): Many users prefer clicking a physical button while their phone is in their pocket. Allowing the Volume Up button to count as a tap is a great Pro feature.
		Instead of just showing the time, allow users to set an alarm specifically for Brahma Muhurta (approx. 1.5 hours before sunrise), which is the ideal time for Japa.

2. Tech stack and other technical details
App platform
	Platforms: Android + iOS (cross‑platform).
	Framework: Flutter (Dart).
	UI libraries: standard Flutter widgets (Material / Cupertino compatible).
	Target environments:
		Android 7+ (API 24+).
		iOS 14+.
Tech stack (Flutter app)
	Programming language: Dart + Flutter.
	State management:
		Prefer Provider or Riverpod (simple, testable, good for medium‑size app).
	Local data storage:
		SQLite via sqflite or Drift (drift.dev) for japa sessions, mantras, user‑prefs.
	Panchang data:
		Pre‑computed JSON or CSV (for 1–3 years).
		Stored in assets and copied to app DB on first run.
		Since you are using a local JSON for Panchang, remember that sunrise/sunset times change based on the city. You might need to ask for a one-time "General Location" (City level) to ensure the Panchang data is accurate for their specific zone.
	Sensors / compass:
		Use device sensor APIs (Android + iOS via Flutter).
		Library: sensors_plus or similar Flutter sensor package for heading.
	Notifications:
		Local notifications only (flutter_local_notifications).
		Example: “Time for morning japa” at sunrise / Brahma‑muhurta (from panchang).
	Internationalization:
		flutter_localizations, by default user default language
	Multi Device Sync
Future backend (Pro‑only, v2+)
	Backend role:
		Leaderboards.
		Optional analytics (if user opts in).
	Recommended stack (suggestion):
	Backend:
		Firebase (Firestore + Auth) OR Node.js + PostgreSQL.
	Tech stack hints (if AI generates it):
		REST API or GraphQL endpoints.
		Endpoints:
			POST /sessions → submit user session.
			GET /leaderboards/weekly → list top users per mantra.
			GET /leaderboards/monthly → list top overall.
		User‑identity (optional and minimal):
			On‑device random user‑ID (UUID).
			No email / phone by default; option to add later (optional field).
	Design / UX style
		Overall feel: calm, minimal, spiritual.
		Colors:
			Soft pastels (saffron, light blue, deep burgundy) in Pro mode;
			Simple neutral palette in Free mode.
		UI principles:
			No flashy ads, no pop‑ups, no interstitials.
			“Pro” unlock: 1–2 gentle prompts only (e.g., on Panchang / Compass / Settings screen).
		Accessibility:
			Large tap targets.
			Clear text and icons.
